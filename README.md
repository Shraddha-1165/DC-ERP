# DC ERP — Fictional Student Portal

A React and Vite demo portal with Home, Academic, and HMC navigation. It is a fictional educational mockup and is not connected to IIT Jodhpur's ERP.

## Run locally

```powershell
npm install
npm run dev
```

The sign-in page uses local demo accounts:

| Login ID | Password |
| --- | --- |
| `demo.student` | `Demo@123` |
| `demo.staff` | `Staff@123` |
| `demo.admin` | `Admin@123` |

For a production build:

```powershell
npm run build
```
